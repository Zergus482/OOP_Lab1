# Как установить CommunityToolkit.Mvvm

## Способ 1: Через консоль (рекомендуется)

1. Откройте терминал в папке проекта **Lab_1** (там, где лежит файл `Lab_1.csproj`).
2. Выполните команду:

   ```bash
   dotnet add package CommunityToolkit.Mvvm
   ```

3. Готово. Пакет будет добавлен в проект, и его можно использовать.

---

## Способ 2: Через Visual Studio

1. В **Обозревателе решений** щёлкните правой кнопкой по проекту **Lab_1**.
2. Выберите **Управление пакетами NuGet...**.
3. Перейдите на вкладку **Обзор**.
4. В поиске введите: **CommunityToolkit.Mvvm**.
5. Выберите пакет **CommunityToolkit.Mvvm** (автор: Microsoft).
6. Нажмите **Установить** и примите условия лицензии.

---

## Что даёт пакет

- **ObservableObject** — базовый класс для ViewModel с поддержкой уведомлений об изменении свойств (INotifyPropertyChanged).
- **Атрибут [ObservableProperty]** — по полю автоматически генерируется свойство с уведомлениями (меньше ручного кода).
- **Атрибут [NotifyPropertyChangedFor]** — при изменении одного свойства можно автоматически уведомлять о другом (например, вычисляемое свойство).
- **RelayCommand** и **[RelayCommand]** — удобная реализация команд для кнопок и действий.

Пакет использует **source generators**, поэтому после установки дополнительная настройка не нужна — достаточно наследоваться от `ObservableObject` и помечать поля атрибутами.
